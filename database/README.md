# قاعدة البيانات

- التطوير المحلي: التطبيق ينشئ قاعدة SQLite تلقائيًا في `data/sog_moderator_portal.db` عند التشغيل الأول.
- الاستضافة العامة: استخدم PostgreSQL مُدارة واضبط متغير البيئة `DATABASE_URL` في منصة الاستضافة.
- لا ترفع قاعدة `*.db` إلى GitHub، لأنها قد تحتوي طلبات اللاعبين وكلمات مرورها المشفّرة وسجلات إدارية. مجلد `data/` موجود في المستودع فقط لتوثيق المكان.
- الجداول تُنشأ من نماذج SQLAlchemy المعرّفة في `app.py` عبر `db.create_all()` عند بدء التطبيق. الملف `schema.sql` مرجع اختياري لبنية SQLite فقط، والتطبيق لا يحتاج استيراده يدويًا.
- خذ نسخًا احتياطية من قاعدة الإنتاج من لوحة مزود PostgreSQL أو عبر `pg_dump`، وخزّنها خارج المستودع وبوصول محدود.
